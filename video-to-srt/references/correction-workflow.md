# SRT Correction Workflow

## Goal

基于上下文修正错别字、专有名词和断句，同时保证每个字幕块只有一行文本，且单行不超过 18 个字。

## Steps

1. 先生成原始 `.srt`。
2. 如果用户提供术语表，先运行 `scripts/replace_terms_in_srt.py` 做一轮确定性替换。
3. 通读整份字幕，重点找：
   - 同音词误识别
   - 专有名词误写
   - 上下文冲突
   - 断句过碎或明显不通顺
4. 如果某一行超过 18 个字，在前面的自然气口处拆成新的字幕块和新的时间戳。
5. 生成纠错版 `.srt` 时，每个字幕块只保留一行文本。
6. 运行 `scripts/validate_srt.py`，确认结构没有被破坏。

## Safe Prompt Pattern

让 Codex 修正字幕时，使用类似约束：

```text
请基于上下文修正这份 SRT 字幕中的明显错别字和专有名词误识别。
每个字幕块只能保留一行文本，每行不能超过 18 个字。
如果某一行超过 18 个字，请在前面的自然气口处拆成新的字幕块和新的时间戳。
如果没有足够依据，不要臆测。
```

## Common Targets

- 人名、地名、学校名
- 博物馆、展览、作品名
- 品牌、软件、课程名
- 常见中文同音错字
